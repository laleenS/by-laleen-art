# by_laleen

My personal art portfolio website, with a gallery of artwork and a section for
commission enquiries. The site uses HTML, CSS, and JavaScript.

Visitors can filter the gallery, open images for a closer look, and use the
Instagram link to ask about commissions. There is no checkout or payment system.

## View locally

From the project folder, run:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000` in a browser. No packages or build step are needed.

`index.html` is the main page. `flowering-garden-preview.html` is a separate design
preview with placeholder studies, not the main artwork gallery.

The web-development side of this project focuses on gallery filtering, image
navigation, and making the layout work on smaller screens. Enquiries are handled
through Instagram rather than an on-site form.
